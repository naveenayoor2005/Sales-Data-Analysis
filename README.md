
# Sales Data Analysis

## Project Overview
This beginner-friendly project analyzes sales data using Python.

## Tools Used
- Python
- Pandas
- Matplotlib
- VS Code

## Objectives
- Calculate total sales revenue.
- Identify best-selling products.
- Analyze monthly revenue.
- Visualize sales trends using charts.

## How to Run
1. Install the required libraries:
   `python -m pip install pandas matplotlib`
2. Run the program:
   `python sales_analysis.py`

## Files
- `sales.csv`: Sample sales dataset.
- `sales_analysis.py`: Python analysis code.
- `README.md`: Project documentation.

## Expected Result
The program calculates sales revenue and generates product sales and monthly revenue charts.
